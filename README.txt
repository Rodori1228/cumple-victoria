REGALO PARA VICTORIA

Abre index.html en un navegador para ver la página.

PERSONALIZACIÓN
- Sustituiremos los tres espacios de fotos por fotos reales de Victoria.
- Añadiremos sus canciones favoritas (con enlaces de Spotify/YouTube o reproductores permitidos).
- Cambiaremos los ejemplos de comidas por sus platos y dulces favoritos.
- Reemplazaremos los textos de recuerdos por anécdotas reales.
- La carta actual es un primer borrador y podemos adaptarla a tu forma de hablar.

PARA COMPARTIRLA
El archivo index.html funciona localmente. Para que Victoria pueda abrirlo desde cualquier lugar, habrá que publicarlo en un servicio de alojamiento web estático (por ejemplo, GitHub Pages o Netlify). Puedo guiarte paso a paso cuando esté personalizada.
